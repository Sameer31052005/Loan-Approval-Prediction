SECTION 2

Introduction Page

2.1 Background & Motivation: Loan distribution forms the core revenue generator for commercial banks, yet unmanaged credit default introduces Non-Performing Assets (NPAs). Manual evaluation takes days and is subjective to human underwriting bias. Automated machine learning provides instant, standardized, and unbiased risk determination.

2.2 Problem Statement: Formulate a supervised binary classification system to accurately predict whether a loan application should be Approved (Y) or Rejected (N) based on historical borrower parameters.

2.3 Dataset Description: Utilizes a Kaggle-aligned synthetic Loan Prediction dataset (10,000 instances) comprising demographic factors (Gender, Education, Marital Status), financial capability (Applicant & Coapplicant Income, Loan Amount, Term), and the decisive historical parameter: Credit_History.

SECTION 3

Project Flow (Frontend, Backend & Integration)

  • Frontend Architecture: Interactive modern web UI featuring live financial sliders, credit record toggles, 1-click simulation personas, and a holographic decision HUD with real-time radial probability gauges.
  • Backend Architecture: RESTful API server implemented with Python and Flask. Handles missing data imputation, categorical feature encoding, total household income aggregation, and loads the serialized Scikit-Learn Decision Tree model (loan_decision_tree_model.joblib).
  • Integration Flow: Communication occurs asynchronously via HTTP POST (/api/predict). When the user evaluates the form, the frontend serializes input parameters into JSON, transmits to Flask, runs model inference in ~12ms, and returns the verdict, probability percentage, and explainable decision steps.
